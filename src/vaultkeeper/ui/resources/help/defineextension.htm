Define an extension map

Refine Mod Installer creation ›› Work with the Extensions map ››

Use this procedure to define extension names that the Installer Tool supports.


  1. Press Insert or click New Extension to add a new extension name to the map.
  2. Type in the extension name and click Create.
  3. Click Default Folder from the menu and select the Installation or User Files folder that will be used for files with the extension you defined.
  4. If files with this extension can be placed in an alternative folder, click Secondary Folder from the menu and select the folder name.
  5. Click in the Exceptions panel and press Insert or click New Exception to specify a Secondary Folder usage condition. Type in the text that a file name must start or end with and click Create.
  6. Click Save when you have finished specifying the attributes for your new exception.
