Remove Groups

Work with Groups ››

Use this procedure to remove one or more existing Groups along with its associated Mods...


  1. Select one or more Groups to be deleted.
  2. Press Delete or click Delete from the Edit menu.
  3. Unless you have disabled confirmation messages in Advanced Settings, you are asked to confirm your request.
  4. All Mod folders belonging to the Groups you selected are moved to the Recycle Bin (or permanently deleted if you have disabled the Recycle Bin in Advanced Settings).
