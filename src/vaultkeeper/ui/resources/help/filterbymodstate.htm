Filter by Mod State

Use the Mod Explorer ›› Use Filter Boxes to specify filtering criteria ››

Click the Mod State filter box () to display a menu defining the installation status of Mods to include in the list. Select the state you want to use as a filter.


The mod list is updated based on the value you selected.


You can also change how the state you select is used to filter the mods. For example, to list Mods that are installed without any conflicts, select Matching Mod State from the state filter menu.


The list now displays Mods that do not have any file conflicts.


To show Mods that are not installed, select Less files installed from the state filter menu.


The list shows uninstalled Mods.


You can show all installed Mods by choosing More files installed and selecting Some files not installed, some overridden.



Click Clear from the state filter menu to remove your Mod State filter criteria.
