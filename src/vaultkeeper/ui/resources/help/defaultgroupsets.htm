Default Group Sets

Work with Groups ››

A Group Set is predefined collection of Group names that provide a starting point for organising your Mods. You can use, remove or change these to suite your own tastes. All default Group names include a numeric prefix to ensure a specific sequence is maintained, which helps you manage Mod file conflicts.


The first time you load a Profile, you are asked to specify your Group Set preference.
