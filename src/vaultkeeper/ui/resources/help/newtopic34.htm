Status Bar

Get Started ›› User Interface ››

The Status Bar contains Mod, Group and Status information as well as a number of clickable Status Icons.

Mod count information: Number of Mods installed / Total number of Mods.

You can click Mods: to display the Recent Mods list.

Group information for the selected Mod or Group, which comprises the Expand/Collapse icon, Name and Number of Group's Mods installed / Total number of Mods in the Group.

You can click the Group Name to toggle the Expand/Collapse status.

Click Group: to display the Go to Group menu.

Status information.



Status icons that you can click. You can move the mouse over each icon to see a description of the icon's purpose.

Click the Information icon to view the change report.

The Error Log icon is displayed after Neverwinter Nights writes information to the AR_ERROR.LOG or nwclienterror1.txt files. Click the icon to view the information.

The Character Restorer icon is shown when the selected Mod has an associated Character Restorer. Click the icon to open the Character Restorer Viewer, which lists all the Character Files. You can select a file to display the character's summary information.

Click the Restorer button to select the Character Restorer in the Mod List.

See Use the Character Explorer for more information.

You can Right-Click the icon to display Character Summary Information for the latest game save.

The Associated Mod icon is shown when the selected character Restorer has an associated Mod. Click the icon to select the Mod in the Mod List.

Click the Display Create Installer Wizard Report icon to view the results of the Wizard from the last Create Installer operation.

You can Right-Click the icon to open the Wizard Builder.



Click the Selection Preferences icon to specify which Contents and Details items are selected when you view a Mod.

Hover the mouse over the icon to see your current preferences.

You can Right-Click the Selection Preferences icon to open the Document Organiser.

You can also specify these behaviours on the Preferences page in Advanced Settings.


The Overwrite icon toggles whether existing folders and files are overwritten when copying or moving files. The option you set remains active for the duration of the current Installer Tool session.

When you start the Tool again, the icon reflects the behaviour you defined for Overwrite directories and files when copying or moving on the Preferences page in Advanced Settings.


The Recycle Bin icon toggles whether deleted folders and files are moved to the Recycle Bin.  The option you set remains active for the duration of the current Installer Tool session.

When you start the Tool again, the icon reflects the behaviour you defined for Move deleted items to the Recycle Bin on the Preferences page in Advanced Settings.

You can Right-Click the Recycle Bin icon to open the Recycle Bin.
