Add or Remove Groups

Use the Installation Manager ›› Work with Installation Sets ››

You can include additional Groups in your Installation Set or remove existing Groups.


  1. Select the Installation Set you want change and press Ctrl+G or click Selector.
  2. Clear the tick (uncheck) the Group you want to remove from your Installation Set.
  3. Tick (check) the Group you want to include in Installation Set.
  4. Click Save when you have finished making changes.
