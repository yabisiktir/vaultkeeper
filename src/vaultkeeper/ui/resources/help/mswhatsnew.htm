NWN Installer Tool version 7.4.1

Released: 28 February 2026

This is a stability release.

Bug Fixes: 5. Miscellaneous: 2.

Release Notes

Bug Fixes

  • Addresses a rare issue where using the Game Saves Manager's Open with File Manager crashes the Installer Tool.
  • Addresses an issue where a Rules excluded Project is still listed when the Project URL is invalid.
  • Addresses some of the issues where inaccurate information is returned for Project Pages after the migration of The Vault.
  • Addresses an issue where, under certain circumstances, an incorrect Mod folder is used for Required Projects direct links to files.
  • Addresses a rare issue where Profile Data is not saved due to a file conflict with another task.

Miscellaneous

  • FAQ updated with "How can I view NWN information about classes, skills and feats?".
  • Updated the Installer Tool to comply with Visual Studio Analyser recommendations.
