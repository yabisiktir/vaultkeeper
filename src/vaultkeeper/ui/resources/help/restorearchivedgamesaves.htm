Restore archived Game Saves

Work with Game Saves ››

Each time you use Reduce game saves, the Manager creates a folder describing the range of game saves that have been moved to the game's archive folders (eg 000101-000130).


You can only perform this operation on the game you are playing (ie you cannot Restore backup game saves). 


  1. Select the active game (always the first item in the list) and press Ctrl+Plus or click Restore.
  2. Select the Games Saves range you want to restore and click Restore.

    You can hover the mouse over the location text (North Road in the image above) or the Game Saves Range heading to display NWN's save image for the selected save.
  3. The archived saves are moved to NWN's game saves folder and the information area updated to reflect the change.
