Change the Hak Patch sequence

Use the Manage menu ››

The order in which Hak Patch files are defined in the nwnpatch or userpatch ini file defines the priority of each Hak. This means that if there are conflicts between elements of different Hak files, the one that is lower down in the order overrides the one that is higher in the order.



Existing entries in your nwnpatch or userpatch ini are saved the first time you run the Installer Tool so that the your initial hak patch priorities are retained. After this, the Installer Tool only uses its recorded priorities to construct the ini file.


The Installer Tool constructs the nwnpatch or userpatch ini file based on the Patch folder contents. The Tool maintains a record of Patch Hak files detected so that you can change the priority (sequence) that is used to resolve conflicts.


Click Hak Patch Priority from the Manage menu to access the Priority Editor. Use the Up and Down arrows to change the order in which Hak Patch files are applied. Click Save when you have finished viewing or changing priorities.


When you start the Hak Patch Priority Editor, the existing information is validated to add missing entries or remove hak files that no longer exist.
