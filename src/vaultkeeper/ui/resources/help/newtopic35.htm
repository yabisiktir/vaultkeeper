Quick Access Toolbar

Get Started ›› User Interface ››

The toolbar provides a quick way to access selected Installer Tool commands.


The Quick Access Toolbar is only visible when you hide the Ribbon interface.


Use the Options menu to specify whether the toolbar is displayed and shows icons with or without text as well as access the Customise Toolbar dialogue.
