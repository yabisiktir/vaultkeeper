Customise the Installer Tool ››

Use the Run Menu page in Advanced Settings to define programs, program shortcuts and files that you want to append to the Installer Tool's Run menu.

If you need to define start parameters for a program, you can create a shortcut with the parameters and add the shortcut to the Run menu.


Click the Edit Icon, Right-Click, Double-Click or press the Space Bar to access the actions menu.

Create a Run menu item

  1. Select the item that will precede your new entry.
  2. Press Insert or click New Menu Item from the actions menu.
  3. Type in the location of the program, shortcut or document or use the Browse button to select a file. The Menu Text is set to the file name you specified, but you can change it to suite your preference.  Use the ampersand character (&) to define an Alt-Key shortcut. For example, &Project Tracking Tool will display Project Tracking Tool when the Alt-Key has been pressed and is launched using the Alt, R, P key sequence (Run, Project Tracking Tool).
  4. Click Create when you have provided the required information. The new item is inserted after the entry you selected in step 1.
  5. Click the Save button when you have finished making changes. Click the Run menu to see your new item.


Use the dropdown menu on the Browse dialogue to switch between selecting executable and document files.
