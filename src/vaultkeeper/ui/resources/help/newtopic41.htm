Rename a document using a Contents Panel name

Use the Tools menu ›› Organise Mod Documentation ››

When you are updating a Mod, some of the documentation files may have been changed. In this case, it can be useful to rename a document using the same name you used for the previous version of the document.


  1. Select the document you want to rename, click Rename to and select the document name you want to use.
  2. The document name is renamed to match your selection. When you click Copy, the Contents Panel file is replaced with the new one.
