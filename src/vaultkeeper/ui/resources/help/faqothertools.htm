How do I handle Mods installed with other tools?

Neverwinter Nights Installer Tool ›› Frequently asked questions (FAQ) ››

Use Create Restorer from the Manage menu to build a Mod Installer containing files copied to your Neverwinter Nights Installation or User Files folder using another tool such as an installation program or Windows File Explorer.


  1. Click Create Restorer from the Manage menu and click Create. This step captures all the files installed on your system by an unknown source before you use an external tool to install files.
  2. Install the files using an external tool such as an installation program or Windows File Explorer.
  3. Click Create Restorer from the Manage menu again, specify the Restorer's Name and Group you want to use for the files installed in step 2, then click Create.


The new Restorer contains all files not installed by NIT. You should now have only the files belonging to the Mod that was installed with the external tool.


You can use Convert Restorer to Mod from the Edit menu to create an Installer Tool managed Mod from the Restorer created in step 3.
