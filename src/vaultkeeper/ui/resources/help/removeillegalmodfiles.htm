Remove illegal Mod files

Use the Manage menu ››

Click Remove Illegal Mod Files from the Manage menu to move any illegal files and folders from the Mod Installer to the Mod's .Removed Items sub-folder. Examples of illegal files are executables or compressed files.


The Installer Tool examines the Installers for all the Mods in your active Profile and moves invalid folders and files to the .Removed Items sub-folder of the Mod containing the invalid items.


You can delete the .Removed Items folder if you don't need to retain its contents.
