Synchronise networked PC Mods

Use the Manage menu ››

The Installer Tool initiates a networked PC synchronisation operation, which runs in the background, when the Tool starts or you load a Profile.


The operation synchronises your active Profile's Play Time information by merging Game Play Time files with those on the networked PC.


The Synchronise Mods option is not shown in the Manage menu unless a Shared NIT Store has been specified on the Locations page in Advanced Settings.


  1. Click Synchronise Mods from the Manage menu to merge Game Play Time files and, if Sync Mod Notes is enabled (Preferences page in Advanced Settings), copy your Mod Notes to the networked PC.
  2. The Tool displays a summary line in the Information area of the Status Bar when the operation completes.


    Pending Mods are Mods in your Profile that are not defined in the networked PC's Profile. This is not a problem and can be disregarded. However, when the missing Mods are added to the networked PC's Profile, they will be synchronised.


Synchronisation operates on the basis that a Profile with the same name is defined on the networked PC. You will see this line in the Status Bar if there is not a corresponding Profile.
