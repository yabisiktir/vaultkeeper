How do I switch from Beamdog's to Steam's Enhanced Edition?

Neverwinter Nights Installer Tool ›› Frequently asked questions (FAQ) ››

If you were using Beamdog's Enhanced Edition and have installed the Steam version, you can specify Steam's Library folder on the Locations page in Advanced Settings.


Steam only works with the default User Files folder in Documents (ie ...\Documents\Neverwinter Nights) unless you enable "Use NIT to manage Steam's Workshop Content" on the Preferences page in Advanced Settings. 


  1. Click Advanced Settings from the Options menu.
  2. Click Locations.
  3. Select Library.
  4. Click the Edit Icon.
  5. Type in the new Library location or use the Browse button to locate the folder and click Save.
  6. Ensure that the default User Files folder in the Documents directory has been created and is specified, unless you have enabled Use NIT to manage Steam's Workshop Content.
  7. Click Save to apply the change to your Settings.
  8. You are now using Steam's Library.
