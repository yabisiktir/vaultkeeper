Reduce file clutter

Work with Mods ››

Most downloaded files added to your Mod are compressed. When you have just added these files, it is convenient to have the Installer Tool extract the contents so you can see its folders and files in the Details panel. Extracting the contents of large compressed files can take some time.


In addition, if there are a large number of files, it makes it harder to see the folders and files in the Contents Panel that you might want to view when you select a Mod.


Here is how to reduce this clutter.


  1. Select one or more Mods to process.
  2. Select Move to Downloads from the File menu.
  3. You can still view the contents of compressed files in the Details panel by clicking Extract compressed file contents in the Properties panel.
