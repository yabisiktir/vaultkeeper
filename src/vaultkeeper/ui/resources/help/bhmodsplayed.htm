How can I see which Mods I have not played for a long time?

Neverwinter Nights Installer Tool ›› Frequently asked questions (FAQ) ››

Click Mods Sorted by Date Completed on the View menu to see a list of Mods sorted by the last date the Mod was completed and ordered from the oldest to the most recent. You may find this list useful when choosing which Mod you want to replay.


Additional Information

Display Help information for Mods Sorted by Date Completed.

Mod List 

Mods are sorted by date completed and Mod name in ascending order (ie the order in which they are shown in the Mod List). The first entry in the list represents the most time that has elapsed since you completed the Mod, while the last entry is the most recently completed Mod.


If you hover the mouse over a Mod in list, a popup message shows how much time has elapsed since you last played the Mod.


Note

The list only includes Mods that have an Installer that contains one or more modules (.mod files).

Buttons

 

Hover over the Filter Options button to see an overview of currently selected options.

Click Only Show Completed to toggle whether to show only the Mods that have a completed time recorded.

Click Show no End Level to toggle whether to show Mods that do not have an End Level defined.

Click the Show End Level Filter Option to specify the End Level values you want to include in the Mod list.


The Show End Level Filter Option is changed to reflect the End Level filter applied.


Click Group and Rating Filters... to display a dialogue that allows you to include or exclude Mods based on the Group and Rating. The ticks indicate which Groups and Ratings are included in the list.



Click Restore selection at start-up to toggle the selection behaviour when you open Mods Sorted by Date Completed. Enable this option to save the selected Mod's position in the list when you press the Select button and restore the saved location when you open Mods Sorted by Date Completed.


Your Filter Options are saved when you close Mods Sorted by Date Completed and applied the next time you view the sorted Mods.
