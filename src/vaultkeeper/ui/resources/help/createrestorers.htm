Create Restorers

Work with Restorers ››

Use Create Restorer from the Manage menu to see if there are any unowned files in your Profile.


The Installer Tool displays this message when all your files have been defined by existing Mods and Restorers.


The Tool displays this dialogue if there are files that have not been defined by your existing Mods and Restorers.

 

Procedure

  1. Type in the name you want to assign to this Restorer.
  2. If the active Group is not the one you want to use, click in the Group box and select the one you want to use.
  3. Click Create after specifying the Restorer Name and Group.
  4. The Restorer is created and selected in the Mod List.
