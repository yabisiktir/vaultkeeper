Uninstall Mods

Work with Mods ››

Uninstalling Mods deletes the files that were copied from your Mod Installer from the Neverwinter Nights Installation or User Files folder. If any Mod Dependencies are defined, NIT ensures that all the required Mods, which are not in use by any other installed Mods, are uninstalled. This is only done when you enable Uninstall Mod Dependencies on the Preferences page in Advanced Settings (disabled by default).


  1. Select one or more Mods to uninstall.
  2. Click Uninstall from the Manage menu.
