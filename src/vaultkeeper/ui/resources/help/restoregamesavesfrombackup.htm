Restore Game Saves from Backup

Work with Game Saves ››

You can restore Backup Game Saves so you can continue playing a previous game that was saved.


  1. Select the game saves Backup you want to use and double-click, press Ctrl+A or click Activate.

    Note:
           You can right-click Activate to install the associated Mod if it is uninstalled.
  2. The Game Saves are restored to Neverwinter Nights game saves folder and the list is updated to reflect the change.
