Rebuild Database

Use the Tools menu ››

There are no predictable circumstances under which it should be necessary to recreate the Installer Tool's database files.


  1. Click Rebuild Database from the Tools menu.
  2. Click Yes if you want to proceed.
  3. The existing database files are moved to the Recycle Bin and the Installer Tool is restarted.
  4. Your Profile is loaded and you are asked to specify your Group Set preference.
  5. The checksum values for all files is calculated. This can take some time to complete depending on how many files need to be processed.
  6. The database has now been rebuilt without your Mod grouping or Property information.


If you have a backup or pre-version 5.0 data files, you can use Recover Groups and Recover Mod Properties from the Tools menu to restore information previously defined.
