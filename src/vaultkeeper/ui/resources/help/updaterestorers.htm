Update Restorers

Work with Restorers ››

You can update an existing Restorers with new or changed files.


  1. Select the Restorer you want to update and click Create Restorer from the Manage menu.
  2. The selected Restorer Name and Group are shown in the dialogue. Click Create.
  3. The Restorer is updated with any changed or additional files.
  4. You can click the Information icon to see details about added or changed files.
