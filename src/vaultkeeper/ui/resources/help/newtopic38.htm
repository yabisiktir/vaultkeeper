How do I create a Download Rule for my Project?

Neverwinter Nights Installer Tool ›› Frequently asked questions (FAQ) ››

Take a look at Contribute to Download Rules, which explains how to create a Rule for your Project and how it can be published for use by other users.


Note

You do not have to define any Rules to deal with Required Projects you have specified, unless you only need specific files from the Required Project.
