Menu Bar

Get Started ›› User Interface ››

Contains menu commands, play time information, the Mod Selector and the Help icon.

Installer Tool command menu items.

Hover the mouse over the Play Time Information to display a summary popup window.

Click the Play Time Information for the current game to view additional details.

You can Right-Click a game's play time information to specify the start date and time retrospectively.

Press the Report button to see how much time you spent playing for each day of the month. You can also display the report by pressing the Control key when you click Play Time Information.

Use the Mod Selector to find and select specific Mods.

   

Click the Help icon to display the Installer Tool's guide.
