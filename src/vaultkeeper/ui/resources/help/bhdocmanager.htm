Organise Mod Documentation

Use the Tools menu ››

Use this tool to review Mod documentation (eg ReadMe) in your downloaded files. There is often useful information that can help avoid issues when you use the Mod.

The Documentation Organiser is only available after the _Downloads folder has been created (Move to Downloads).


The Documentation Organiser makes it easy to review and copy Mod documents in downloaded files as well as view documentation in the Contents Panel. You can select one or more Mods to process.

Remove or Restore version number from Document names.

Discards any name changes you made to documents that originally contained a version number.

Rename a document.

The renamed file is automatically marked for copying (ie Checked).

Rename a document using a Contents Panel name.

The renamed file is automatically marked for copying (ie Checked).

Display Windows File Properties for the selected document.

Reload the contents of the Downloads folder and Contents Panel. Any document name changes and Copy selections you made are discarded.

Clears all document files marked for copying. In other words, clears the ticks or unchecks all items in the document list.

This can be useful when there are a large number of documents detected and you only want to copy a few of them to the Contents Panel.

Downloads Folder
Documents

List of the document files detected in the Downloads folder and includes the contents of compressed files (eg 7z, rar, zip, etc).

Document names shown in italics and a grey colour indicate that the file matches one of the documents in the Contents Panel. These cannot be marked (ticked) for copying.

Contents Panel Documents

List of document files detected in the Mod's Contents Panel.

Grey coloured document names in italics indicate that the file matches one of the documents detected in the Downloads folder.

Copy the ticked documents to the Contents Panel and close the Document Organiser.

Process the next selected Mod in the Mod List.

This is only shown when more than one Mod has been selected for processing.
