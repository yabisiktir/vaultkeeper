Find files in Contents or Details

Perform Find Operations ››

You can locate files in a Mod's Contents or Details List.


  1. Select the Mod name you want to search.
  2. Specify which area to search by clicking in the Contents or Details List.
  3. Press Ctrl+F or click Find from the Edit menu.
  4. Type in the text you want to use locate the files you want to select and click Find Next.
  5. The first occurrence of the file is selected in the list. Each time you click Find Next, the next matching item is selected.
         
  6. The Find dialogue tells you when there are no more occurrences of files that match your criteria.
  7. You can click Previous to search in the reverse direction.
