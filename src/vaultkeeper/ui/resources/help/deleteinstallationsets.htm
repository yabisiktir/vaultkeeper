Delete Installation Sets

Use the Installation Manager ›› Work with Installation Sets ››

You can remove Installation Sets and Checkpoints that are no longer relevant.


  1. Select the Checkpoint or Installation Set you want to remove and press Delete or click Delete.
  2. Click Save to update the information on disk.
