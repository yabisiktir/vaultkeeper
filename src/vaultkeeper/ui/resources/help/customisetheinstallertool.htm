Customise the Installer Tool

The Installer Tool uses information defined on the pages in Advanced Settings to control many aspects of how it behaves as well as elements of the user interface.


Click Basic Settings on the Options menu to customise key preferences and user interface configuration options.


Click Advanced Settings on the Options menu to access all Preferences and user interface configuration options.


You can use these pages to customise the behaviour as well as the look and feel of the Installer Tool to suite your tastes and preferences.


See Change Theme Colours and Customise Theme colours for more information on Theme colours.


You can click the Settings items in the illustration to view more information.
