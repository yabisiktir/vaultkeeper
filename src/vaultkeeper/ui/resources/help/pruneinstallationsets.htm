Prune Installation Sets

Use the Installation Manager ›› Work with Installation Sets ››

Use Prune to remove uninstalled Mods from an Installation Set's Mod list.


  1. Select the Installation Set containing uninstalled Mods (ie no tick) and press Ctrl+P or click Prune.
  2. The Mod list is updated to reflect the removal of uninstalled Mods from monitored Groups.


If your reinstall pruned Mods, they are added to list of Mods in the monitored Groups.
