How do I use my Neverwinter Nights Mods in the Enhanced Edition?

Neverwinter Nights Installer Tool ›› Frequently asked questions (FAQ) ››

You can import Mods exported from your Neverwinter Nights Profile into an Enhanced Edition Profile.


  1. Click Load Profile from the File menu and select the Neverwinter Nights Profile containing the Mods you want use in the Enhanced Edition.
  2. Select the Mods you want to use in the Enhanced Edition and click Export from the File menu.
  3. Click Load Profile from the File menu and select the Enhanced Edition Profile.
  4. Click Import from the File menu and select the Mods you exported in step 2.
  5. Click Import.
  6. You can now install and use the Mods in the Enhanced Edition.
