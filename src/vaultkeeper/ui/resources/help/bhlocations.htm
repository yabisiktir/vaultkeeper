Specify program and file Locations

Customise the Installer Tool ››

When you first start the Installer Tool, it establishes where the programs, files and folders it needs reside on your PC. There are some optional Locations as well as items you may want to change. This illustrates the Locations you can specify and Surazal's assigned values.


Click the Edit Icon, Right-Click, Double-Click or press the Space Bar to open a Browse window or display an options menu.


Select a Location to display details in the information panel.
