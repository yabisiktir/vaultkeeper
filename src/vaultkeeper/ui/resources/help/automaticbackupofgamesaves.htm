Automatic backup of Game Saves

Work with Game Saves ››

When you open the Games Saves Manager, it examines the contents of your Neverwinter Nights game saves folder to see if you have saves for more than one Mod. For example, if you are playing a mod that automatically loads the next chapter, there will be saves for at least two different mods.


If multiple mod game saves are detected, the Game Saves Manager creates backups for each of the mods so that the Neverwinter Nights game saves folder only contains saves for the latest mod being played.


Quick Saves and Auto Saves are left in the Neverwinter Nights game saves folder regardless of the Mod with which they are associated.
