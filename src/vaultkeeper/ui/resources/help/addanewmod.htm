Add a new Mod

Work with Mods ››

Use this procedure to define new Mods.


  1. Press Ctrl+M or click New Mod from the Manage menu.
  2. Type in the name of your Mod.
  3. If the Group shown is not the one you want to use for the new Mod, select the correct Group from the dropdown list.
  4. Click Create.
  5. Your new Mod is selected in the Mod list.
