Download and install Mods from other sites

Work with Mods ››

One of the most common tasks you perform is downloading Mods from Internet Sites and copying the required files to the correct NWN Installation or User Files folders.


The Installer Tool is designed to make this much simpler by automating many of the tasks you need to perform. These procedures list the steps you can use to create Mod Installers.

You can click the illustration above to navigate to the relevant topic.


Use Download Project to download Neverwinter Vault Project files.

Procedure

  1. Download all the files required to install and play the Mod.
  2. Select New Mod from the Manage menu to create the Mod Folder you will use to store the Mod's assets.
  3. Select Add Files to Mod from the File menu, select the files you downloaded in step 1 and click Open.
  4. Press Ctrl+L or select Create Installer from the Manage menu. 
  5. Select Install from the Manage menu.
  6. You are now ready to use the Mod.

Recommended Procedure

  1. Download all the files required to install and play the Mod.
  2. Select New Mod from the Manage menu to create the Mod Folder you will use to store the Mod's assets.
  3. Click the Add Link icon to record the Mod's web page address (URL).
  4. Select Add Files to Mod from the File menu, select the files you downloaded in step 1 and click Open.
  5. Reduce the number of files in the Contents panel by moving files used to create the Installer to NIT's -Downloads folder.
  6. Review Mod documentation in the files you downloaded.
  7. Press Ctrl+L or select Create Installer from the Manage menu.
  8. Review the contents of the Mod Installer.
  9. Select Install from the Manage menu.
  10. You are now ready to use the Mod.
