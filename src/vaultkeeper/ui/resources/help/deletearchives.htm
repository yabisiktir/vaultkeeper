Delete archived Game Saves

Work with Game Saves ››

Each time you use Reduce game saves, the Manager creates a folder describing the range of game saves that have been moved to the game's archive folders (eg 000101-000130).


You can only Delete archived Game Saves for the game you are playing. 


  1. Select the active game (always the first item in the list) and press Ctrl+Plus or click Restore.
  1. Select the Games Saves range you want to remove and click Delete.
  2. Click Yes to confirm the delete operation.
  3. The selected range is moved to the Recycle Bin or permanently deleted depending on your Recycle Bin for Game Saves Preferences setting.
  4. The Restore Archived Game Saves dialogue is closed when all ranges have been deleted.
