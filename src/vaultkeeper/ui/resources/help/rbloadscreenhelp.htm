Use NWN's Start Screen Manager

Use the Manage menu ››

The Start Screen Manager is intended to make it easy to select and change the Neverwinter Nights start screen image. The Manager...


  • Consolidates all the images you use or want to use or view in one place.
  • Simplifies viewing your collection of images and editing the ones you want to change.
  • Saves you having to manually create a Wizard to provide start screen selection.
  • Allows you to use descriptive file names for your start screen collection because it handles the required gui_pre_bknd3.tga name change on installation.
  • Provides very fast start screen image installation in comparison with standard Mod Installations.
  • Offers an option that automates cycling through your Start Screen images each time you play Neverwinter Nights.

Technical Information

Get Started

  1. Select NWN's Start Screens from the Manage menu.
  2. Answer Yes to initialise the Start Screen Manager.
  3. You will see something like this if you have already installed a Start Screen image...


    Otherwise, this is what you see when using the default Neverwinter Nights start screen...
  4. You are now ready to add your own load screen images.


You can Right-Click Play Neverwinter Nights on the Ribbon to open the Start Screen Manager.

Pressing the Control key when you Right-Click Play Neverwinter Nights displays the currently installed Start Screen.

Add start screen images

  • Use the Add Images from Folders button to select one or more folders that contain TGA or compressed (7-Zip, etc) files to process.
  • Use the Add Image Files button to select one or more TGA files.


This is what it looks like after clicking Add Images from Folders and selecting the Custom Menus Mod's Download folder...


Right-Click the start screen name or the image to see a menu of operations you can perform.

File and Folder Processing

  • If the source file name is gui_pre_bknd3.tga, then the file is copied to the name of the folder containing the file. For example, Fire dragon with archer\gui_pre_bknd3.tga is copied to Fire dragon with archer.tga.
  • If there is more than one Folder\File combination, the duplicate is not copied.
  • If the file is already defined in the Start Screen Manager, it will not be copied.

Find Images

You can search for specific images by typing part of the image name you want to find or clicking theSearch icon in the status area and then entering your search criteria.

A search box is displayed so you can see what you entered and use the Up and Down arrows or buttons to navigate through the images matching your criteria. The standard Start Screen navigation options will also use your search criteria.


  • The search capability is only enabled when you have 10 or more start screen images.
  • Press the Escape key to clear or close the search box.
  • Adding folders or files and renaming or deleting files closes the search box.

Use the Options Menu


  • Auto-Start Screen Selection.
    Enable this option to install the next start screen image each time you close Neverwinter Nights. This allows you to see a different start screen each time you start Neverwinter Nights. You can also set this option on the Configuration page in Advanced Settings.

    This option is ignored if you uninstall the Start Screen Manager Mod (see Uninstall the Start Screen's Mod).
  • Add to Auto Exclusions List (Shown when Excluded is No).
    Adds the currently selected image to the Automatic Start Screen cycle exclusion list so that the start screen is not shown when using Auto-Start Screen Selection.  You can also click the Excluded Status Text to perform the Add.
  • Remove from Auto Exclusions List (Shown when Excluded is Yes).
    Removes the currently selected image from the Automatic start screen cycle exclusion list so that the start screen is shown when using Auto-Start Screen Selection. You can also click the Excluded Status Text to perform the Remove.
  • View Information Report.
    Click this option to view a summary of included and excluded start screen images, which includes a list of your Automatic start screen image exclusions. You can click Remove Exclusions to clear all the listed start screens.


    You can also click the Start Screens Statistics Text to display the Information Report.
    Hover over the Start Screens Statistics Text to display the summary portion of the report.
  • Import Start Screen Files
    This option imports any Start Screen Image Files that have been exported on the Shared NIT Store machine.

    This option is only available when you define a Shared NIT Store on the Locations page in Advanced Settings.
  • Clear Exported Start Screen Files
    Permanently deletes the folder containing Start Screen Image Files that have been exported.

    This option is only available when you define a Shared NIT Store on the Locations page in Advanced Settings.
  • Slide Show Interval
    Use this option to specify the number of seconds that the Start Screen Slide Show displays each image when automatically cycling through each image (ie Shift+Click Start Screen Slide Show).
  • Continuous Slide Show
    Enable this option to start at the first Start Screen after the last one has been shown rather than closing the Start Screen Slide Slide Show window when automatically cycling through each image (ie Shift+Click Start Screen Slide Show).
  • Uninstall the Start Screen's Mod.
    This option performs a standard NIT Uninstall operation for the Start Screen Manager's installed image. If there is another Installed Mod containing a gui_pre_bknd3.tga file, then it will be used. Otherwise the standard Neverwinter Nights start screen is used.
  • Remove the Start Screen Manager.
    Use this option to stop using the Start Screen Manager. You will be asked to confirm this action before proceeding.

    You can select NWN's Start Screens from the Manage menu if you want to use the Manager at a later date.

Export Start Screen Image Files

This function is only shown on the Ribbon and Right-Click menu when you define a Shared NIT Store on the Locations page in Advanced Settings.


  1. Select one or more Start Screen Files in the list.
  2. Click Export Start Screen File from the ribbon or Right-Click menu.
  3. The status bar indicates how many files have been exported.


The files are automatically imported the next time NIT is started on the Shared NIT Store machine or when Import Start Screen Files is selected from the Options menu.

Create your own start screen

This is the procedure I use...


  1. Ensure you have an image editor program that can save images in TGA file format (eg Paint.net).
  2. Open the image you want to use as a start screen with your image editor program.
  3. Change the image size to match your screen's resolution (eg 1920x1080). You should maintain the Aspect Ratio and, if necessary, crop the Width or Height to match the screen's resolution.
  4. Save as the image as a TGA formatted file using a descriptive file name.
  5. Open the Start Screen Manager, click Add Image files and select the file you saved in step 4.
  6. You have just created your own start screen.

The recommended minimum size for proportional scaling to most resolutions is 738 x 251.

Technical Information

The Start Screen Manager works by creating a standard Mod, which has an Installer that contains gui_pre_bknd3.tga in the Override folder.


After the initial creation and installation of the standard Mod Installer, the Manager uses a fast streamlined install process to change the installed Start Screen.
