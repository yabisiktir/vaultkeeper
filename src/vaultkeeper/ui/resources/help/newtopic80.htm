Module Data IFO File

Reference ›› Technical Information ››

Overview

The Module Data IFO File contains information used to determine the Mod's Game Save Name for modules that do not define the Game Save Name or Description.


The Module Data IFO.txt file is downloaded from the URL specified for BaseLazWorksUrl in the Application Definitions File's [NWN Installer Tool] section. If the download fails, the file is read from the Installer Tool's installation directory.


The file is refreshed asynchronously when NIT is started.

Format

#Module:Mod_File_Name

ModSavName=Name to use as the Game Save Name

Module description text


Note

  • Keywords and Values are case sensitive.
  • Leading spaces are taken as part of the Value.

#Module

Specifies the name of the module.

ModSavName

The name of the file that will be used by NWN to save a game. The best way to determine this, is to look at the Mod's saved game (.sav) in the Games Saves folder.

Module description text

The description for the Mod. You can usually get this using NWN' Toolset or, if not defined, the Project Page.

When does the file need updating

NIT's Log File will contain an entry that you lets you know when the file needs to be updated. It will look something like this...


12:16:27.381 ― Mod_Name value not found: E:\NIT Store\Profiles\Enhanced Edition Mods\Music Player\.Mod Installer\modules\DEMO-Music-Playerv2.mod

12:16:27.381 ― Update NIT's Module Data IFO.txt for: DEMO-Music-Playerv2.mod


After updating Module Data IFO.txt, it should be uploaded to the online location specified in the Application Definitions File. You should also update the file in NIT's Visual Studio's Project (...\Visual Studio 2022\Projects\NWN Installer Tool\NWN Installer Tool\bin\Debug\Module Data IFO Rev 1.txt).


Note
The Rev only needs to be incremented when you change the file's format. Previous revisions should be retained for backward compatibility.

Example

Here is what the file entries look like...


#Module:The_Lord_of_Terror_2_0_5.mod

ModSavName=The Lord of Terror 2.0.5

The Lord of Terror - The Diablo Campaign (v2.0.5)


This is a remake of the original Diablo game published by Blizzard Entertainment, along with its expansion, Hellfire, published by Sierra Online.  This reimagining of the Diablo saga features all the original quests, plus additional story-related side quests that will further enhance the engrossing story of the Diablo saga.


This module was created by Tolitz Rosel.  Version 1.06 last updated November 27, 2004.  For game hints and walkthrough, visit http://nwn.tolitz.com/lordofterror/


Version 2.0.0 and beyond updated and enhanced by Jeff McClure in 2024, https://github.com/jeffmcclure/lot https://github.com/jeffmcclure/lot

#Module:DEMO-Music-Playerv2.mod

ModSavName=DEMO Music Player

NUI - Music Player


Music Player adds a bard-inspired music selection system.

Players can open a custom NUI window, browse available tracks, and play them using a handcrafted Play button.

Music can be shared across the area (e.g., in taverns) or played locally for the player — this mode requires NWNX.


The demo focuses on MP3 CBR files (required for reliable seeking/looping — see the tutorial). There are a few minor quirks, but the core functions work as intended.
