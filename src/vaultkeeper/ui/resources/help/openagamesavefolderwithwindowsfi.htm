Open a game save folder with Windows File Explorer

Work with Game Saves ››

You can use Windows File Explorer to view the contents of specific game save folders.


  1. Select the folder you want to view and click the Open with File Explorer icon, double-click the folder, press Ctrl+O or right-click the folder and click Open with File Explorer. 
  2. The folder is opened using WIndows File Explorer.


The same procedure applies for the save folders listed in the Restore dialogue.
