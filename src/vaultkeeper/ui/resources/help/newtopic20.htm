Detect Steam Workshop Subscriptions

Manage Steam Workshop Subscriptions ››

The Installer Tool detects new and changed Workshop Subscriptions when you...


  1. Start the Installer Tool.
  2. Click Save after enabling "Use NIT to manage Steam's Workshop Content" on the Preferences page in Advanced Settings.
  3. Select Refresh Workshop Files from the Tools Menu.
  4. Click Refresh in the Installer Tool's Steam Workshop Subscriptions viewer.
  5. Load or reload an Enhanced Edition Profile.

Detection Process

  1. Each time a new or changed subscription is detected, the Installer Tool calculates and records checksum values for all files in the Workshop item.
  2. If a user friendly Mod name cannot be derived for a new Subscription, you are asked to specify one or use the generated default name.
  3. Type the name of the subscription in the Mod Name box and click Apply.
  4. Workshop Mods that are not already defined are added to your Profile's Mod list and installed. For updated Mods, the Workshop archive files are updated, Mod Installers re-created and, if necessary, re-installed.
