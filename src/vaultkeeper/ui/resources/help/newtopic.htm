How do I uninstall the Neverwinter Nights Installer Tool?

Neverwinter Nights Installer Tool ›› Frequently asked questions (FAQ) ››

Uninstall the Installer Tool program

  1. Use Programs and Features in the Control Panel to uninstall the Neverwinter Nights Installer Tool program. For Windows 10, click NWN Installer Tool in the Apps & Features list to get to Programs and Features.
  2. Click NWN Installer Tool and, if required, answer Yes to the confirmation message.
  3. You can permanently delete the User Configuration files containing your Settings and the NIT Store folder, which holds your Mod definitions as well as any downloaded files.
  4. The Installer Tool's program files and Start menu items are removed from your system.

Manually remove the Installer Tool's configuration files

This step is only necessary if you did not delete the User Configuration files when you uninstalled NIT via Programs and Features.


  1. Open Windows File Explorer.
  2. Ensure that hidden files are visible by clicking Options from the View tab.
  3. Open the Surazal folder in your AppData directory (you can paste C:\users\%USERNAME%\AppData\Local\Surazal into the File Explorer's address bar).

    Locate the folder containing the version 5.0's configuration (it starts with NWN_Installer_Tool).
  4. Delete the folder to remove the Installer Tool's configuration files (user.config).

Manually remove files managed or created by the Installer Tool

This step is only necessary if you did not delete the NIT Store Folder when you uninstalled NIT via Programs and Features.


Follow this procedure if you want to remove all the Mods you managed with the Installer Tool and the associated data files that were created.


  1. Open Windows File Explorer.
  2. Navigate to the NIT Store folder you specified when you ran the Tool for the first time (eg E:\NIT Store, \Documents\NIT Store, etc).
  3. Delete the folder.
