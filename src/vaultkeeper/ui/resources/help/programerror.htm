Program Error

Neverwinter Nights Installer Tool ›› Frequently asked questions (FAQ) ›› The Installer Tool crashes every time I start it ››

You should see an error message that asks you to attach the NWN Installer Tool Error Log.txt file to the new email message that has been opened.


Please send the email with error information attached so I can investigate and resolve the issue.


If the error occurs when you run the Installer Tool for the first time, then there is little I can suggest to get you operational, other than sending the diagnostic information.


If you get this error before the Installer Tool has loaded your profile, you can try follow the procedures for Corrupted Settings and Corrupted Profile Data to see if this gets you going again.
