Reduce the number of NWN Game Saves

Work with Game Saves ››

It is possible to have hundreds of game saves, which can cause Neverwinter Nights to be slow when loading and, on occasion, may cause crashes on certain machine configurations.


The Game Saves Manager provides a feature that allows you to "prune" some of the saves that have been performed by moving a range of save folders to the Manager's archive folders. These can also be restored if required.


You can only perform this operation on the game you are playing (ie you cannot Reduce backup game saves). 


  1. Specify the number of Neverwinter Nights game saves to retain. You can type in a number or use the arrows to increase or decrease the value.
  2. Select the active game (always the first item in the list) and press Ctrl+Minus or click Reduce.
  3. The information panel is updated to reflect the result of the archive process.
