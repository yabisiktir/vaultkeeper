Mod List

Get Started ›› User Interface ››

The Mod List contains a list of all the Mods in the loaded Profile. Work with Mods has more information.

Contains a list of all the Mods in the loaded Profile. The Mods are listed alphabetically within Groups, which are also in alphabetical order.

You can click a Group's icon to show or hide its Mods.

You can click a Mod's install status icon to Install or Uninstall a Mod.
