Save your customised INI files

Get Started ›› Deal with existing installed Mods ››

The Installer Tool creates and maintains a copy of all your INI files. You can use these files to make a Mod that contains the changes you have made to your INI files so they can be restored at any time.


  1. Create a Mod for your customised INI files.
  2. Click Create Installer from the Manage menu to create an empty Mod Installer folder.
  3. Select all the INI files in the generated NWN INI Files (Auto) Mod and click Copy from the Edit menu.
  4. Select the Mod Installer folder in the Custom INI Files Mod you created in step 2 and click Paste from the Edit menu.
  5. You can now restore your customised INI files at any time.
