How can I see portraits from a Mod's hak file?

Neverwinter Nights Installer Tool ›› Frequently asked questions (FAQ) ››

Follow this procedure if you want the Character Summary Information to display a portrait image stored in an installed Mod's hak file...


  1. Download the ERF Utility (Erf.exe v1.2.2 including source).
  2. Extract the contents of the file you downloaded and copy the erf.exe to a suitable location on your system (eg Utilities\ERF Utility)
  3. Click Advanced Settings from the Options menu and select the Locations page.
  4. Click the ERF Utility Executable's Edit Icon so you can select the erf.exe from the folder you created in step 2.
  5. Click the Save button.


After completing the above steps, Extract Portrait Images will be available on the File and context menus when a HAK file is selected and allows you to store the HAK's portrait files for use by the Character Summary Information dialogue.
