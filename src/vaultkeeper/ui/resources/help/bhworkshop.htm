Manage Steam Workshop Subscriptions

When you subscribe to a Workshop item, Steam downloads the required files to your Steam Library so that it is available when you run Neverwinter Nights. Workshop content is available only when you run Neverwinter nights from Steam or a Steam generated shortcut. The latter is how the Tool runs Neverwinter Nights for Steam users.


If you start Neverwinter directly by clicking ...\SteamLibrary\steamapps\common\Neverwinter Nights\bin\win32\nwmain.exe, the workshop content is not available.


You may want to use the Installer Tool to manage your Steam Workshop Subscriptions when...


  1. You have Steam installed, but use Beamdog or Gog to play the game and want to take advantage of Workshop Mods that are only available via Steam.
  2. You are a Steam user, but want to use the Installer Tool so you can specify the User Files Folder rather than using Steam's default (Documents\Neverwinter Nights) or as an alternative to Steam's Neverwinter Nights Launch Options.
  3. You use Steam, but hope to avoid the occasional problem where the Workshop Subscriptions are not available when you play Neverwinter Nights.


Note

The Workshop Management features and menu functions are only available in Profiles defined for the Enhanced Edition and are unavailable in Neverwinter Nights 1.69 Profiles.


You have to use Steam to update existing subscriptions or download the files for new ones.
