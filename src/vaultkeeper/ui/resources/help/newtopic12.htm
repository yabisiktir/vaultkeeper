You can open the Rules in Notepad++ by selecting Download Rules File on the View menu or clicking the Open Download Rules File icon on the Download Project dialogue.


You can make navigating the rules easier by clicking Fold All from Notepad++’s View menu or pressing Alt+0.


You can then expand the Region of interest to add a new definition or locate the one you want to change.

Expand the Project Rule Definition Help region for rule syntax and statements.
