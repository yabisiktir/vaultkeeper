Windows Management Instrumentation error detected

Neverwinter Nights Installer Tool ›› Frequently asked questions (FAQ) ››

This message is displayed when the Installer Tool detects that the Windows Management Instrumentation (WMI) service is not operating correctly.


WMI may not be enabled on your machine or it might be corrupted. You can try this procedure to correct the problem...


  1. Right-Click the Windows Start Menu, select Terminal or Command Prompt.
  2. Type net stop winmgmt and press Enter.
  3. Open Windows File Explorer and navigate to your wbem folder (eg C:\Windows\System32\wbem).
  4. Right-Click the Repository folder and rename it (eg Repository.bak).
  5. Restart your computer.
  6. Right-Click the Windows Start Menu and select Terminal or Command Prompt.
  7. Type net stop winmgmt and press Enter.
  8. Type winmgmt /resetRepository and press Enter.
  9. Restart your computer again.
  10. The WMI message should no longer be displayed when you start the Installer Tool.
  11. You can delete the renamed folder after you have checked that everything is working as normal (or use it to restore everything back to how it was).
