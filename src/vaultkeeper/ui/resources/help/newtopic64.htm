Automatic Properties Panel Height

Use the Options menu ››

Enable Automatic Properties Panel Height to automatically adjust the height of the Properties Panel based on the type of item selected.


The height will be the same as the Mod Properties panel when a file list is displayed and adjusted to accommodate the five lines of information about the file selected in the Contents Panel.


You can click the Properties Panel heading to toggle the Automatic Properties Panel Height option.
