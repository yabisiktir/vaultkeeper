Mod and File Status Icons

Reference ››

Descriptions of the status icons are displayed in the Mod Properties and Details Property panels.


This icon

Means

None

The Mod does not have a Mod Installer.

The Mod or File is not installed.

The Mod or File is installed.

Some or all of the Mod's files have been overridden by other Mods, but the files are identical.

The file has been overridden by another Mod's file, but the files are identical.

All the Mod's files have been overridden by other Mods.

The File has been overridden by another Mod's file.

Some, but not all, of the Mod's files have been overridden by other Mods.

The Mod is not installed, but some of its files already exist in the NWN installation or User Files folders.

The Mod is not installed, but some if its files already exist in the NWN installation or User Files folders and would be overridden by another Mod's files.

The Mod is not installed, but some if its files already exist in the NWN installation or User Files folders and would be overridden by another Mod's identical files.
