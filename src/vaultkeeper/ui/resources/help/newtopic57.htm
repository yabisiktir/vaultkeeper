The Installer Tool has messed up my INI file

Neverwinter Nights Installer Tool ›› Frequently asked questions (FAQ) ››

The Installer Tool updates your NWN and UserPatch ini files. You can restore the original ini files from the .BAK files that are created in the same location as the original files. This is usually Documents\Neverwinter Nights for the Enhanced Edition and NeverwinterNights\NWN for the original game.


The Tool updates your NWN ini file to ensure the Game Saves directory is specified in the [Alias] section of the file. You can use the Locations page in Advanced Settings to set the Games Saves Folder to Blank, which will stop the Tool from changing your INI file.

You can also Use the Alias Section Editor to specify the location of the folders defined in the Alias Section of the current Profile's NWN.ini file.
