Rename a document

Use the Tools menu ›› Organise Mod Documentation ››

You can rename document files to make identifying its contents easier.


  1. Select the document you want to rename and click Rename.
  2. Edit or type in the name you want to use for this document.
  3. Press Rename when you have finished specifying your new name.
  4. The Downloads Folder Documents list is sorted using the changed name.
