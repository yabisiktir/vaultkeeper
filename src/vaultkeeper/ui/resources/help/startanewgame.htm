Work with Game Saves ››

When you open the Game Saves Manager after saving a new Neverwinter Nights game, the Manager automatically moves the saves for the previous games you were playing to the Installer Tool's game backup folder.


Follow these steps if you want to retain the saves for the game you are currently playing and start another game.


  1. Select the active game (always the first item in the list) and double-click, press Ctrl+D or click Deactivate.

    Note:
           You can right-click Deactivate to uninstall the associated Mod if it is installed.
  2. The first entry indicates that Neverwinter Night's game saves folder is empty and the game you deactivated is selected in the list.
  3. You can now start playing a new game.
