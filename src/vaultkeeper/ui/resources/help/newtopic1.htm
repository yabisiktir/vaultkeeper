Create Restorers to backup installed Files

Get Started ›› Deal with existing installed Mods ››

You can use Restores to create a backup of all the files you have copied to your Neverwinter Nights installation folders.


  1. Click Create Restorer from the Manage menu, tick (check) Create NWN character Restorer and click Create to make a copy of all your character files.

  2. Click Create Restorer from the Manage menu and click Create to make a copy of all your existing Mod files.

  3. You are now able to restore your character and Mod files at any time.
