Change Installer Options

Use the Manage menu ››

Use Change Installer Options to re-create the Mod Installer so you can select different options or preferences when the Wizard runs.



This feature works best when you enable "Only install mods that were already installed" in Basic Settings (or "Restore Mod installation state after Installers have been created" on the Preferences page in Advanced Settings).


Change Installer Options is only enabled and shown on the Ribbon's Play tab when you select a Mod that has a Wizard file or Rules-based Wizard defined with Choices or Preferences specified.
