Glossary

Reference ››


Term

Explanation

Checksum

A synonym for a CRC value.

CRC

Cyclic redundancy check. A CRC value is a unique digital signature or value that the Installer Tool computes for each file it manages and is used match files or detect when files have been changed.

The Installer Tool uses the same algorithm as Zip, 7-Zip and WinRar to compute CRC values.

Extended Edition

Synonym for the Enhanced Edition. The Extended Edition was used to refer to the Enhanced Edition in previous versions of the Installer Tool. The erroneous reference was changed in version 5.0.4.

Focus

The term used to describe which part of the Installer Tool's User Interface is active. For example, when you click on a Mod name, the Mod List becomes active and is described as having the Focus.

Group Set

A predefined collection of Group names that provide a starting point for organising your Mods.

Mod

The name you used to group downloaded files containing modifications to Neverwinter Nights (eg modules, hak packs, etc). The Mod name is used as the folder name within a Profile.

Mod Installer

Folder containing all the files that need to be installed to use a Mod.

Neverwinter Nights Folder

The Neverwinter Nights Installation or Enhanced Edition User Files folder.

Original Restorers

Predefined Restorers containing files installed by the Neverwinter Nights or Enhanced Edition setup program.

Profile

A Profile defines a set of Mods that are associated with a Neverwinter Nights Installation or an Enhanced Edition User Files folder.

Restorer

Special Mod Installer containing original or unowned files that can be used to restore contents when a Mod is uninstalled as well as create backups of character and other unowned files.

Unowned file

 A file that is present in the Neverwinter Nights Installation or User Files folder and does not exist in any of your Profile's Mod folders.
