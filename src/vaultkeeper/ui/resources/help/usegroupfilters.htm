Use Group Filters

Use the Mod Explorer ››

Group filters control whether to include or exclude Mods belonging to a specific Groups.


Checked (ticked) Groups are included in the Mod list and unchecked Groups are excluded.


You can undo the changes you have made to the Group filters by clicking the Group Filter heading or Undo Group Changes from the Tools menu.
