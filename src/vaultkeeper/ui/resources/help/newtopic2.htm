Create NIT Mods from Restorers

Get Started ›› Deal with existing installed Mods ››

You can use files from Restorers to create Mods so you can record information and play times about the Mods that were installed by other tools such as the Windows File Explorer.


  1. Select the Mod files in the Details panel that you want to use to define the NIT Mod and click Copy from the Edit menu or the toolbar.
  2. Click New Mod from the Manage menu, type the name you want to assign to the Mod, select the Group in which it should be created and click Create.
  3. Click Create  Installer from the Manage menu or the toolbar.
  4. Click in the Details panel and then click Paste from the Edit menu or toolbar.
  5. Click Install from the Manage menu or toolbar so that the Mod is shown as installed.
  6. You can now record the Mod's Web Page Link, make notes and record information.
