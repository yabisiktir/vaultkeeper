Add Mods from downloaded files

Work with Mods ››

This feature is intended to be used for Installer Tool formatted 7-Zip files (see Publish Mods).


  1. Select the Group you want to use for the downloaded Mod.
  2. Click Add Mods from Files from the File menu, select the Installer Tool formatted 7-Zip files and click Open.
  3. The Downloads folder contains the 7-Zip file you added and is ready for installation.
