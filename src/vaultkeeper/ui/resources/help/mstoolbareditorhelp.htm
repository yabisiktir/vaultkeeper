Customise the Quick Access Toolbar

Customise the Installer Tool ››

Use the Quick Access Toolbar Editor to add, remove or edit toolbar items.


  1. Select the Menu Command you want to add and its position in the ToolBar Commands, then click Add >>
  2. The Toolbar Commands list is updated with a new entry.
  3. You can shorten the text that will be displayed under the icon and then click Save.
