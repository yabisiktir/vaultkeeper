Installer Tool Shortcuts

Press this key

To do this

Alt

Display Alt-Key Shortcuts

The Alt-Key shortcuts are highlighted by underlining the shortcut characters.

Ctrl+A

Select All

Select all the items in a list or all the text in a text area.

Ctrl+Alt+C

Copy Name

Copies the names of the selected Groups, Mods, folders or Files to the Windows Clipboard.

Ctrl+C

Copy

Places the selected folders, files or text on the Windows Clipboard for copying.

Ctrl+F

Find

Displays the Find Files in Profile or Find dialogue.

Ctrl+G

New Group

Ctrl+L

Create Mod Installer

Ctrl+M

New Mod

Ctrl+Minus

Collapse all Groups.

Ctrl+O

Open

Opens the selected folder or file with its associated program.

Ctrl+Plus

Expand all Groups.

Ctrl+R

Mod Explorer

Displays the Mod Explorer.

Ctrl+V

Paste

Copies or Moves folders, files or text from the Windows Clipboard.

Ctrl+X

Cut

Places the selected folders, files or text on the Windows Clipboard for moving.

F1

Help

Displays help based on what is being displayed. Usually corresponds to clicking the Help Icon .

F2

Rename

Displays a Rename dialogue for the selected item.

Game Save Manager Shortcuts

Press this key

To do this

Alt

Display Alt-Key Shortcuts

The Alt-Key shortcuts are highlighted by underlining the shortcut characters.

Ctrl+A

Activate

Moves the selected Backup game saves to the Neverwinter Nights Saves folder.

Ctrl+D

Deactivate

Moves the game saves from the Neverwinter Nights Saves folder to the Game Saves Manager's Backup directory.

Ctrl+Minus

Reduce

Reduces the number of game saves in the Neverwinter Nights Saves folder by moving a range of game saves directories to the Game Saves Manager's Archive folder.

Ctrl+Plus

Restore

Moves the selected ranges of game saves from the Game Saves Manager's Archive folder to the Neverwinter Nights Saves directory.

F1

Help

Displays Game Save Manager help. Corresponds to clicking the Help Icon .

Installation Manager Shortcuts

Press this key

To do this

Alt

Display Alt-Key Shortcuts

The Alt-Key shortcuts are highlighted by underlining the shortcut characters.

Ctrl+C

Checkpoint

Create a new Installation Set checkpoint.

Ctrl+G

Selector

Shows or hides the Group Selector list.

Ctrl+N

Create Set

Create a new user defined Installation Set.

Ctrl+P

Prune

Remove uninstalled Mods from an Installation Set.

F1

Help

Displays Installation Manager help. Corresponds to clicking the Help Icon .

F2

Rename

Rename an Installation Set.

Mod Documentation Organiser Shortcuts

Press this key

To do this

F1

Help

Displays Mod Documentation Organiser help. Corresponds to clicking the Help Icon .

F2

Rename

Rename a document.

F5

Reset

Reload the contents of the Downloads folder and Contents Panel.

F8

Version

Remove or Restore version number from Document names.

F9

Rename to

Rename a document using a Contents Panel name.

F12

Properties

Display Windows File Properties for the selected document.
