Find files in your Profile

Perform Find Operations ››

You can search for files in the active Profile using criteria to reduce the number of items shown in the list.


  1. Click on an item in the Mod List.
  2. Press Ctrl+F or click Find from the Edit menu to display the Find Files in Profile dialogue.
  3. Type in your search criteria, select the file you want view and click Select.
  4. The file you selected is displayed in the Installer Tool's user interface.


You can also display Property information and, if the correct type of file is selected, image or character summary information.
