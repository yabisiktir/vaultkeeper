Application Definitions File

Reference ›› Technical Information ››

Overview

The Application Definitions File provides a mechanism for maintaining hard-coded values without having to update and release applications when values are changed.


The file uses an INI file format and is best viewed with Notepad++'s Language set to "INI file".

Format

[Section Name]

Keyword=Value


Note

  • Section Names, Keywords and Values are case sensitive.
  • Leading spaces are taken as part of the Value.

Revision Keyword

Any section that contains the Revision keyword will be written to a local file when the online Revision number is greater than the local one supplied with the application.

Changing the location of the Applications Definitions File

This procedure should only be used for experimental purposes or in the event that Surazal is no longer available and you need to take over the maintenance of the Download Rules file or other keyword values.


Applications released by Surazal include an Applications Definitions File as part of the installation package. This file (Application Definitions.txt) is read first and used to read to the online version of the file.


Newer versions of the file are automatically written to a local copy that is held in the NIT Store's Data folder. If NIT detects this file, then it will be read instead of the one installed by the Setup and Run program.


You can copy the packaged Applications Definitions File to \NIT Store\Data and edit the Location1 and Location2 keyword values in the [LazWorks Library] section to point to a new location. The next time NIT is launched, it will use the new locations you defined.


You will need to upload the changed file to make it available to other users.


When a new version of NIT is installed, the local copy in the NIT Store's Data folder is deleted. This action is taken because the packaged version of the file is always copied from the online Application Definitions File.

[Application Version Information]

This section defines the latest version of an application and is used to determine when an update is available.


Assembly Name=major.minor.build.revision


Example: NWN Installer Tool=6.3.0.14


Version information is always read from the online file and is not copied to the local disk when other changes are detected.

[LazWorks Library]

This section defines hard-coded values that are referenced by LazWorks Library.


Revision

This a numeric value that must be incremented each time a change is made.

CountPhp

PHP statement that is prefixed to file URLs to ensure the download count is incremented.


This value must be copied from NWN Installer Tool's Download Rules File.

FileIdPrefix

Prefix added to file name identifiers when using the download count PHP statement.


This value must be copied from NWN Installer Tool's Download Rules File.

GoogleFavIcons

Used to build the URL to access Google's S2 service, which returns the icon associated with the specified web address.

HelpFolderNames

A list of sub-folder names used by programs to store HTML files.


Format: Foldername1,Foldername2,...


► There must be no leading or trailing space characters.

LocationN

Specifies the base URL that is used to host the Application Definitions file.


A numeric value is appended to the keyword "Location" and specifies the order in which attempts are made to read the file.


Location1 is the primary source, Location2 is the secondary source, etc.


The Location keywords must be specified in ascending order.

VaultDomain

Vault domain used for URL validation.


This value must be copied from NWN Installer Tool's Download Rules File.

VaultFavIcon

The URL for The Neverwinter Vault's FavIcon image.

VaultForumNew

The URL for "Topics with new and updated posts" on The Neverwinter Vault.


The type (http or https) must be omitted from the URL.


Example: ://neverwintervault.org/forum/new

VaultTitleId

The string appended to Project Title on The Neverwinter Vault.


This value must be copied from NWN Installer Tool's Download Rules File.

[NWN Installer Tool]

This section defines hard-coded values used by the NWN Installer Tool.


Revision

This a numeric value that must be incremented each time a change is made.

BaseLazWorksUrl

Specifies the base URL that is used to host the Download Rules file (DownloadRulesV3.txt). This is the primary location.

BaseNexusRulesUrl

Specifies the base URL that is used to host the Download Rules file. This is the secondary location and is only used if the Installer Tool is unable to read the file hosted on the BaseLazWorksUrl.

BeamdogSupportPage

Link to Beamdog's support page.

MapExcludeExceptions

Map Exclude Exceptions.


This is a list filenames that are omitted from NIT's Create Installer exclude processing.


Format: FileName1.ext*FileName2.ext*...


► Filenames must include the file extension.
► Use an asterisk (*) to separate file name entries.
► There must be no leading or trailing space characters.


Example: MapExcludeExceptions=Test of the Sun.mod*My Test.mod

Cep2xPrefix

This the case sensitive prefix used to identify CEP v2.x files (eg "cep2_2_").

CepFull

This is the case sensitive string included in the CEP download filename denoting the complete CEP installation file (eg "full"). 

CepPartialNames

This is a list of partial name prefixes used to detect CEP v2.65 download file names. Each prefix is delineated by a comma (eg "cep_2_65,cep2_2_65")

CepWizardTitle

This is the CEP Installation Wizard Title defined in the Download Rules files (eg "CEP v2.x Installer Wizard").

NexusNeverwinterNights

Link to Neverwinter Nights on Nexus Mods.

NitForumPageUrl

Link to the Installer Tool's forum page.

TheNeverwinterVault

Link to The Neverwinter Vault.

ValidInstalledExtensions

A list of file extension names that are normally excluded from Mod Installers, but are included as part of the Neverwinter Nights installation.


Format: .Extension1,Folder1,Folder2,...;.Extension2,Folder1,Folder2,...


► Extension names must start with a period (.).
► Use an asterisk (*) to denote that any folder is valid.
► Use a semi-colon (;) to separate extension name entries.
► There must be no leading or trailing space characters.

► Exe must not be defined (included by NIT).


Example: ValidInstalledExtensions=.log,*;.gif,ovr;.json,mod,nwm

ValidInstalledFilenames

A list of file names that are normally excluded from Mod Installers, but are included as part of the Neverwinter Nights installation.


Format: Filename1,Filename2,...


► There must be no leading or trailing space characters.

► Patch.ini.bak and UserPatch.ini.bak must not be defined (included by NIT).


Example: ValidInstalledFilenames=2dasource.zip,cryptographic_secret

VaultArchiveRemoveChars

A list of characters that are removed by The Neverwinter Vault when generating the filename for uploaded files. For example, TheCapulet's Verdant Wilderness Pack Rev 1.7z is changed to thecapulets_verdant_wilderness_pack_rev_1.7z.


Format: Character1[Character2]...


► There must be no leading or trailing space characters.


Example: VaultArchiveRemoveChars='’

[NWN File Type Descriptions]

This section defines the descriptions for the various types of files used by Neverwinter Nights. The installer tool uses these descriptions as the content for Additional Information displayed in the Properties panel when files are selected in the Mod Installer folder's Details panel.


Revision

This a numeric value that must be incremented each time a change is made.

.File Extension Name

This is the file's extension name and must be prefixed by a period character (.). Descriptions are terminated by a new line.


.Extension=Description


Example: .bic=Neverwinter Nights character file.


Setting the description text to nothing (.ext=) indicates that the text will be retrieved from the selected file. This is only applicable for .MOD and .NWM file types.
