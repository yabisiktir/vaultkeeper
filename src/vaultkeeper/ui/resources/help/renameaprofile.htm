Rename a Profile

Work with Profiles ››

When you rename a Profile, the Installer Tool renames the Profile's directory in the NIT Store's Profiles and Data folders.


Use the Profiles page in Advanced Settings to rename a Profile.


  1. Select the Profile you want to rename, press F2 or click the Edit Icon and select Rename Profile.
  2. Type the new name for the Profile and click Rename.
  3. Click the Rename button apply the change.
