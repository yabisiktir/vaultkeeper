The Installer Tool crashes every time I start it

Neverwinter Nights Installer Tool ›› Frequently asked questions (FAQ) ››

These are the most common reasons that cause the Installer Tool to crash when you start it...


  1. Corrupted Settings.
  2. Corrupted Profile Data (information the Installer Tool stores about your Profiles, Mods and Files). 
  3. A Program Error (bug).
