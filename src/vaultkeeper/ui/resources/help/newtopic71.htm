Create Installer did not include all the files from the downloaded archives

Neverwinter Nights Installer Tool ›› Frequently asked questions (FAQ) ››

You used Create Installer to define the files that will be installed from a Mod you downloaded, but files you expected to be included are not present.


The most common cause of this is information defined on the Map Excludes page in Advanced Settings. You can confirm this by selecting NIT Log File from the View menu. Scroll down to the Installer Created entry, which lists the files excluded from the Installer as a result of Map Excludes definitions.


Here is an example of the Log File entry after creating an Installer for CEP v2.x...


10:01:45.765 — CEP v2.x Installer created. Files: 73. Duration: 00:00:37.173. Map excluded files: 6.

    CEP - Starter 270 - Added Tilesets.mod

    CEP - Starter 270 - All the Optional Haks.mod

    CEP - Starter 270 - Extended + Added Tilesets.mod

    CEP - Starter 270.mod

    CEP 1 Open Day.mod

    CEP 1 Starter Module.mod


You can resolve this issue by amending your Map Excludes definitions or manually coping the files you need from the downloaded archive to the Mod Installer.


You can submit a file name as an exception, if you think the Map Excludes definition should be retained. I will then update the Application Definitions file so that the file is not subject to Map Excludes processing.

An example of this is Lone Wolf 01 - Test of the Sun.mod, which is normally excluded by the "Test" definition on the Map Excludes page.
