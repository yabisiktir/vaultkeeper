Rename a Group

Work with Groups ››

Use this procedure to rename an existing Group...


  1. Select the Group you want to rename in the Profile's Mod list.
  2. Press F2 or click Rename from the Edit menu.
  3. Edit the existing name or type in a new one and click Rename.


Renaming a Group may take some time to complete if there are a large number of Mod Installer files in the Group, because the properties of each file needs to be changed in NIT's database. In addition, checks are performed to ensure that file conflicts are resolved based on the sorted position of the renamed Group.
