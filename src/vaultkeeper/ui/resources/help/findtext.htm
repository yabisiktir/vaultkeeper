Find text within a file

Perform Find Operations ››

You can locate text within the contents of files shown in the Details or Properties panels.


  1. Select the text file you want to search and click in the text display area.
  2. Press the Find button, Ctrl+F or click Find from the Edit menu.
  3. Type in the text you want to locate and click Find Next.
  4. The first occurrence of the text you specified is highlighted in the file's contents.
  5. The next occurrence of the text is highlighted each time you click Find Next. The dialogue indicates when there are no more occurrences.
  6. You can click Previous to search in the reverse direction.
