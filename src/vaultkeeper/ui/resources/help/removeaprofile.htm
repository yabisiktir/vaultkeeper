Remove a Profile

Work with Profiles ››

When you delete a Profile, the Installer Tool deletes the Profile's directory in the NIT Store's Profiles and Data folders. The deleted folders are moved to the Recycle Bin, unless you have changed the default option on the Preferences page in Advanced Settings.


Use the Profiles page in Advanced Settings to remove a Profile.


  1. Select the Profile you want to remove, press Delete or click the Edit Icon and click Remove.
  2. Unless you have disabled the Confirm Actions on the Preferences page in Advanced Settings, you are asked to confirm that you want to delete all your Mod folders and NIT database files associated with the selected Profile.
  3. The Profile is flagged for deletion and will be removed when you click the Save button.
