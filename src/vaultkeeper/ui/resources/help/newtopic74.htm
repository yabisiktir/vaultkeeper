The Installer Tool removes my nwnpatch or userpatch ini file changes

Neverwinter Nights Installer Tool ›› Frequently asked questions (FAQ) ››

The Installer Tool automates the creation of the nwnpatch or userpatch ini file, which is why any changes you make to the file are overwritten. This automation cannot be disabled, so you need to use the Tool to maintain the nwnpatch or userpatch ini file.


Existing entries in your nwnpatch or userpatch ini are saved the first time you run the Installer Tool so that the your initial hak patch priorities are retained. After this, the Installer Tool only uses its recorded priorities to construct the ini file.


The Installer Tool constructs the nwnpatch or userpatch ini file based on NWN's Patch folder contents. The Tool maintains a record of Patch Hak files detected so that you can use Hak Patch Priority Editor to change the priority (sequence) used to resolve conflicts.


If a Mod you downloaded includes a nwnpatch or userpatch ini file, Create Installer uses the ini file entries to determine which hak files should be placed in the NWN's Patch folder. The ini file is not used to create the nwnpatch or userpatch ini file used by Neverwinter Nights.


The Installer Tool only includes entries in the nwnpatch or userpatch ini file for hak files that are present in the Neverwinter Nights Patch folder.
