Rename Installation Sets

Use the Installation Manager ›› Work with Installation Sets ››

You can rename Checkpoints and Mod Installation Sets.


  1. Select the Installation Set you want to rename and press F2 or click Rename.
  2. Edit or type in a new name for your Installation Set and click Rename.
  3. Click Save to write the updated information to disk.
