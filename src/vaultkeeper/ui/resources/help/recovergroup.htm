Recover Group information

Use the Tools menu ››

It is possible to lose information about Groups and the Mods that belong to them due to database corruption or some other unforeseen situation. Your first recourse to resolve a problem of this nature is to restore your latest Backup.


  1. Click Backup Data from the File menu to ensure that you can restore information if the result of the recovery is unsatisfactory.
  2. Click Recover Groups from the Tools menu, select where you want to obtain Group information from and click Recover.
  3. Profile Data Backup
    Select the backup you want to use and click Restore.


    Browse for file to use
    Select a pre-version 5.0 nit.GroupData_Format_001 file or a version 5.0 nit.ModData_Format_002 file and click Open.


  4. Group recovery can take some time if there are a lot of changes required.
  5. Group information is recovered and the results displayed in the Information area of the Status bar. Files may be copied as a result of changes in priority for conflicting files.
