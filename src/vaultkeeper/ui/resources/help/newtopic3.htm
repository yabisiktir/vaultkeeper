Specify the Neverwinter Vault Project page

Work with Mods ›› Download and install Neverwinter Vault Projects ››

This procedure illustrates the easiest way to retrieve information about Projects you want to use or play.


  1. Use The Neverwinter Vault site to navigate to the Project page of the Mod you want use or play.
  2. Copy the Project page's web address (URL) displayed in your browser to the clipboard.
  3. Select Download Project from the File menu and click Retrieve (Note that the URL you copied to the clipboard is automatically entered into the Project Web Address box).
