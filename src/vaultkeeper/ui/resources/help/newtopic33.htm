Properties Panel

Get Started ›› User Interface ››

The Properties Panel displays information about the selected folder or file in the Details Panel.

Additional information is displayed when Mod Installer files are selected.


The contents of Text, Rich Text, Batch, INI and HTML files are listed under Additional Information.


You can click the heading to toggle the Automatic Properties Panel Height option, which adjusts the height of the Properties panel based on the type of item selected.


The height will be the same as the Mod Properties panel when a file list is displayed and reduced for file contents.
