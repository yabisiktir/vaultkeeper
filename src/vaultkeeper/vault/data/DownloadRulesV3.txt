' Project Rules Syntax
'
' Project = <The Neverwinter Vault Project Title>
'	ModFolder = <NIT Mod Folder name>
'	Group = <NIT Group name>
'	IgnoreExcludes
'	<Type Keyword>
'		<parameter 1>
'		<parameter 2...>
'	<End ListType>
'	[Installer Wizard Definitions]
' End Project
'
' The ModFolder statement can be used on all Condition Statements except for the "If ERF Downloads".
' Omit the ModFolder statement to use the Project's Title as the default ModFolder name.
'
' Omit the Group statement to use "810.  Evaluating" as the default Group name.
'
' Use the IgnoreExcludes statement to suppress Exclusions for the Project being defined.
'
' Type Keywords and Parameters:
'
' These are listed in the recommended sequence.
'
' 	Downloads
'		<file name portion of attatchment URL 1>
'		<file name portion of attatchment URL 2...>
'	End Downloads
'
'	RoloVaultFiles
'		<address of RoloVault file [&Filename Identifier 1]>
'		<address of RoloVault file [&Filename Identifier 2]...>
'	End RoloVaultFiles
'
'	ExternalFiles
'		<address of external file 1>
'		<address of external file 2...>
'	End ExternalFiles
'
'	If <condition keyword> Downloads
'		[ModFolder = <NIT Mod Folder name>]
'		<file name portion of attatchment URL 1>
'		<file name portion of attatchment URL 2...>
'		[<external keyword> = <file URL 1>]
'		[<external keyword> = <file URL 2...>]
'	End If
'
'	Excludes
'		<file name portion of attatchment URL 1>
'		<file name portion of attatchment URL 2...>
'	End Excludes
'
' 	ExcludeRequiredProjects
'		<The Neverwinter Vault Project Title 1>
'		<The Neverwinter Vault Project Title 2...>
'	End ExcludeRequiredProjects
'
'	ExcludeDirectLinks
'		<address of required file 1>
'		<address of required file 2...>
'	End ExcludeDirectLinks
'
'	RequiredProjects
'		<Project Page URL 1>
'		<Project Page URL 2...>
'	End RequiredProjects
'
'	RequiredFiles From <The Neverwinter Vault Project Title>
'		<file name portion of attatchment URL 1>
'		<file name portion of attatchment URL 2...>
'	End RequiredFiles
'
'	IncludeExtensions
'		<file extension name 1 (including the leading period)>
'		<file extension name 2 (including the leading period)...>
'	End IncludeExtensions
'
' Omit the Downloads statement to include all Project files.
'
' Use the RoloVaultFiles statement to specify files that need to be included from RoloVault.
' For example, the main file for Dragon Dominant is listed in the Project's description as a
' direct link. This is how you would specify this link...
'
'	RoloVaultFiles
'		https://neverwintervault.org/rolovault/projects/nwn1/modules/5132/DragonDominant.exe&fid=7122
'	End RoloVaultFiles
'
' Note: RoloVaultFiles links are case sensitive.
'
' Use the "If <condition keyword> Downloads" to specify criteria for Project file selection.
'
' The Downloads statement must preceed "If <condition keyword> Downloads" statements.
'
' If the Downloads statement is omitted and all "If <condition keyword> Downloads" statements are False,
' all Project files will be included as well as the ones that should have been excluded by the If
' statements. In this situation, you need to specify which Project files should always be included using
' the Downloads statement.
'
' Condition Keywords:
'
'   1.68 - Only download the specified files if NWN's version is 1.68
'   1.69 - Only download the specified files if NWN's version is 1.69
'          or the Enhanced Edition is being used.
'   NWN  - Only download if the Neverwinter Nights original edition is being used.
'   EE   - Only download if the Neverwinter Nights Enhanced Edition is being used.
'   ERF  - Only download if the "Exclude non-Texturepacks ERF files when creating installers"
'          has been Disabled on NIT's Preferences page in Settings.
'
' External Keywords:
'
' These can be used on all Condition Statements except for the "If ERF Downloads".
'
'   RoloVaultFile - Specifies the URL of a RoloVault file.
'   ExternalFile  - Specifies the URL of an externally hosted file.
'
' Use the Excludes statement to specify which files should be excluded from the download list.
' For example birthright_of_the_north.doc is available for download, but is already included in
' the Birthright.zip's archive.
'
' Use the ExcludeRequiredProjects statement to remove Required Projects and their associated files
' from the list.
'
' Use the "RequiredFiles From" statement to specify which files should be downloaded from a Required
' Project (ie specify when a Project does not need to use all Required Project files). This statement
' is ignored if the files defined by the rule for the Required Project have already been downloaded. 
'
' Use the RequiredProjects statement to specify Project Page URLs that have been omitted from the
' Vault's list of Required Projects.
'
' Use IncludeExtensions to specify file extension names that will be included even if the extension
' is specified in the ExcludeRules Extensions list.
